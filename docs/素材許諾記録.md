# 素材許諾記録

本サイト（Milli Orbis）で使用している画像素材の許諾状況を記録します（企画書 §10-3「公式素材の使用」の記録保管）。

## 許諾の内容

- ミリプロ公式への問い合わせにより、公式素材（立ち絵・ロゴ・アイコン等）の「映像以外でも許可」を得ています
- 同じ問い合わせは前作 **Milli Unishare** の構築時に行われており、公式から紹介された実績もあります（許諾が不確実な状態ではありません）
- 問い合わせの日付・手段（メール/フォーム等）は追記予定
