## 4. 運用方法（作業の流れ）

### ページ・データの更新（手動）
1. `data.js` を編集（メンバー情報 / COUNTDOWN / NEWS / GOODS / EVENTS / X_POSTS / HISTORY 等）
2. タレントページの本文を変えた場合は `node scripts/gen-pages.js` で再生成
3. `git add / commit / push` → Render が自動デプロイ（約1〜2分）

### YouTubeデータの更新（自動）
- GitHub Actions が1日6回実行（または Actions タブの Run workflow で手動実行）
- ローカルで試す場合: `YOUTUBE_API_KEY=... node scripts/fetch-data.js`
- 出力: `data/youtube.json`（配信予定・最新動画）、前回分は `data/youtube.backup.json`

### ローカルでの動作確認
- `python -m http.server` で起動してブラウザで確認（`file://` 直開きでは youtube.json の読み込みが失敗するので NG）
- 構文チェック: `node --check scripts/fetch-data.js` 等

### 編集時の注意
- ヘッダー・フッター・ナビは全ページ共通だが各HTMLに埋め込み。変更時は gen-pages.js で再生成する（タレントページ）／index.html を直す
- メンカラーはファン間の慣習色（公式設定ではない）。出典: 非公式wiki（https://wikiwiki.jp/millipro10/ ）
- グッズ商品情報は shop.milpr.com/products.json を参照して手動更新（画像は掲載しない）
- コミットメッセージは日本語で簡潔に（例: `feat: ...` / `fix: ...` / `chore: ...`）

## 5. 絶対に守ること（コンプライアンス）

1. 非公式・非営利であることの明記（フッター常時表示）を消さない
2. グッズ画像・キービジュアル・公式立ち絵の無断使用はしない（許諾済み素材のみ。記録は docs/素材許諾記録.md）
3. タレント間の優劣比較（ランキング・再生回数比較）を掲載しない
4. 生成AI・機械学習の学習素材に公式コンテンツを提供しない
5. 配信音声はミリ創作FAQの許可範囲内のみ（第三者著作物混入禁止・再配布禁止・商用禁止）
6. YouTube API データは YouTube 本編へのリンクを必ず付け、ToS の明記を維持する
